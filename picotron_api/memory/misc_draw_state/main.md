# 0x0054c0 ~ 0x00553f Misc draw state (128 bytes)

## Overview

The miscellaneous draw state

|Address |Value                           |
|--------|--------------------------------|
|0x005510|Camera x coordinate as an i32   |
|0x005514|Camera y coordinate as an i32   |
|0x005528|Low clip x coordinate as an i16 |
|0x00552a|Low clip y coordinate as an i16 |
|0x00552c|High clip x coordinate as an i16|
|0x00552e|High clip y coordinate as an i16|
